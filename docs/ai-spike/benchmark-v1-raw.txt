 # AI Spike — Benchmark v1 (initial extraction contract)

**Status:** Initial exploratory round; five image samples tested once each.  
**Platform:** Ollama  
**Model:** `qwen2.5vl:3b`  
**Goal:** Evaluate vision extraction feasibility before production AI pipeline work.  
**Outcome:** Promising latency and generally strong visible-field extraction, with recurring contract/normalization errors. This is not the v2 checkpoint decision.

This report preserves the original expected values and model outputs as recorded during the exploratory run. The expected values have not been independently re-verified against the original images. They must be reviewed before being used as benchmark ground truth.

## Prompt used for v1

The prompt below is the original v1 prompt, retained to make the results reproducible. It is superseded for the next test round by `tools/ai-spike/run_ollama_spike.py` and the revised extraction contract.

Analiza la imagen del documento y extrae únicamente la información que sea visible.
Devuelve un único objeto JSON válido, sin Markdown ni texto adicional, usando exactamente
la estructura indicada abajo y conservando todas las propiedades.

Reglas:
- Cada campo debe tener "value" y "confidence".
- "confidence" es un número entre 0.0 y 1.0; expresa tu confianza de lectura,
  no es una validación del dato.
- Si un dato no aparece, no se lee con claridad o no puede identificarse sin adivinar,
  usa "value": null y "confidence": 0.
- No inventes, completes ni derives valores.
- Los importes y porcentajes deben ser cadenas decimales con punto y dos decimales,
  sin símbolo de moneda ni separadores de miles.
- year y week deben ser enteros.
- Las fechas deben tener formato YYYY-MM-DD; no deduzcas fechas a partir de year o week.
- Incluye un elemento en details por cada movimiento visible y conserva su orden visual.
- Si el número de operación de un movimiento no se lee, devuelve null; no lo inventes.
- source_commission, source_return_amount y source_totals son transcripciones
  de lo impreso en el documento. No calcules esos valores ni los presentes como
  valores oficiales.
- Si un total no aparece o no puede leerse, conserva la propiedad con value null.

Estructura obligatoria:
{
  "record": {
    "company_name": { "value": null, "confidence": 0 },
    "year": { "value": null, "confidence": 0 },
    "week": { "value": null, "confidence": 0 },
    "week_start_date": { "value": null, "confidence": 0 },
    "week_end_date": { "value": null, "confidence": 0 },
    "affiliation": { "value": null, "confidence": 0 },
    "branch": { "value": null, "confidence": 0 }
  },
  "details": [
    {
      "operation_number": { "value": null, "confidence": 0 },
      "income": { "value": null, "confidence": 0 },
      "commission_percentage": { "value": null, "confidence": 0 },
      "source_commission": { "value": null, "confidence": 0 },
      "source_return_amount": { "value": null, "confidence": 0 }
    }
  ],
  "source_totals": {
    "income": { "value": null, "confidence": 0 },
    "commission": { "value": null, "confidence": 0 },
    "return_amount": { "value": null, "confidence": 0 }
  }
}
